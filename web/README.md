# সমিতি কিতাব ৩৬০ (Samity Kitab 360) - Vercel Web Portal

এই ডিরেক্টরিটি হল **সমিতি কিতাব ৩৬০** এর ক্লাউড ওয়েব পোর্টাল, যা সরাসরি [Vercel](https://vercel.com) এ ১-ক্লিকে ডিপ্লয় করা যায় এবং অ্যান্ড্রয়েড মোবাইল অ্যাপের সাথে রিয়েল-টাইমে সেম টু সেম ডাটা স্ক্যান ও সিঙ্ক রাখে।

## ১-ক্লিক Vercel ডিপ্লয়মেন্ট পদ্ধতি (GitHub Integration):

1. **গিটহাবে পুশ করুন:**
   ```bash
   git add .
   git commit -m "Upload Samity Kitab 360"
   git push origin main
   ```

2. **Vercel এ ডিপ্লয় করুন:**
   - [vercel.com](https://vercel.com)-এ লগইন করুন।
   - **"Add New..."** -> **"Project"** চাপুন।
   - আপনার GitHub রিপোজিটরিটি নির্বাচন করুন।
   - **Root Directory** ফিল্ডে লিখুন: `web`
   - **Framework Preset**: Vite / React
   - **"Deploy"** বাটনে ক্লিক করুন!

3. **লাইভ ফলাফল:**
   - ৩০ সেকেন্ডের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে (যেমন: `https://your-samity.vercel.app`)।
   - মোবাইল অ্যাপের "ভার্সেল ও ক্লাউড সিঙ্ক হাব" থেকে এই লাইভ ইউআরএলটি যুক্ত করলেই মোবাইল এবং ওয়েবসাইটে সব ট্রানজেকশন (যেমন: ১০,০০০ টাকার চাঁদা) ইনস্ট্যান্ট স্ক্যান ও সিঙ্ক হয়ে যাবে।
